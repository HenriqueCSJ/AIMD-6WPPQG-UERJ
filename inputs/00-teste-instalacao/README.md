# Teste de instalação

[← Inputs](../README.md)

Arquivos: [serial](agua_serial.inp) e [paralelo](agua_parallel.inp), ambos dependentes de [agua.xyz](../../estruturas/agua.xyz).

São cálculos pequenos de energia HF/def2-SVP, com 256 MB por processo, para conferir o funcionamento do ORCA. O segundo solicita dois processos. Não são exemplos de AIMD nem validam um modelo científico. Execute um de cada vez seguindo [estas instruções](../../tutoriais/03-testar-instalacao.md).
