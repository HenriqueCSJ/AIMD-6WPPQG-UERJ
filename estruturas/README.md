# Estruturas moleculares

[← Materiais](../README.md#materiais-do-minicurso)

[agua.xyz](agua.xyz) é uma geometria didática não otimizada, em ångström, de H₂O neutra no estado singlete, usada somente para verificar a instalação. Sua origem é uma construção cartesiana simples para este tutorial, não uma estrutura experimental.

Novas estruturas virão acompanhadas de identificação, carga, multiplicidade e finalidade. Os inputs do teste precisam ter uma cópia de agua.xyz na pasta de execução.
